# gio_trash

Обратимая, ограниченная workspace'ом корзина для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH).

DSH в режиме `workspace-write` разрешает агенту менять только файлы внутри workspace. Удалить файл через `rm` внутри workspace можно, но это необратимо; перенести его в системную корзину (`~/.local/share/Trash`) нельзя — это запись за пределами workspace, которую sandbox блокирует. `gio_trash` закрывает этот разрыв: отдельный CLI перемещает файлы в freedesktop-корзину, хранит расширенные метаданные в sidecar-индексе и умеет возвращать файлы, не смешивая разные workspace'ы. DSH подключает CLI как типизированный инструмент (`trash`, `trash_list`, `trash_restore`).

## Ключевые свойства

- **Обратимость**: файл или каталог целиком попадает в системную корзину, а не удаляется.
- **Метаданные**: workspace, исходный путь и относительный путь, имя, размер, SHA-256, даты создания/изменения/удаления, режим, владелец, превью содержимого, манифест каталога.
- **Изоляция**: `list`/`restore` видят только записи своего workspace; восстановление всегда остаётся внутри текущего корня workspace.
- **Совместимость**: корзина freedesktop (`Trash/files`, `Trash/info/*.trashinfo`), записи видны файловым менеджерам и `gio trash --list`.
- **Без ослабления sandbox**: инструмент DSH выполняет перемещение доверенным хост-кодом, а не через `ctx.fs`, и сам проверяет режим sandbox и границы workspace.
